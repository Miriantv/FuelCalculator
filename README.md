🏁 Fuel Calculator App - Cálculo de Combustível

Este é um aplicativo Android desenvolvido em Kotlin que auxilia motoristas a planejarem suas viagens, calculando de forma simples e rápida o custo total com combustível.

O projeto foi desenvolvido como parte do 10D Challenge da Nova Era Tech School, focado em consolidar os fundamentos de lógica de programação e desenvolvimento Android.

📝 Descrição

O Fuel Calculator App permite que o usuário insira a distância a ser percorrida, o preço atual do combustível e a autonomia do veículo. Com esses dados, o app processa as informações e entrega o valor total necessário para completar o trajeto, facilitando o planejamento financeiro da viagem.

🚀 Funcionalidades

• Entrada de Dados: Campos intuitivos para distância, preço e consumo.
• Cálculo em Tempo Real: Processamento lógico para converter entradas em custos reais.
• Validação: Garante que o cálculo só ocorra se todos os campos forem preenchidos corretamente.
• Navegação: Transição suave entre a tela de entrada e a tela de resultados.
• Exibição de Resultados: Apresentação clara do valor final em R$.

🧩 Tecnologias e Conceitos

Este projeto foca nos fundamentos do Android tradicional, sendo uma excelente vitrine de lógica de código:

• Linguagem: Kotlin
• Interface: XML (Layouts estruturados)
• Componentes de UI: EditText, TextView, Button e Toolbar.
• Navegação: Uso de Intent para troca de telas.
• Comunicação: Passagem de dados entre Activities via Bundle.
• Lógica: Conversão de tipos (String para Double) e operações matemáticas.
